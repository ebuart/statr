Global layout rules

Design mobile-first. One main visual anchor per screen, then compact supporting modules below. Avoid desktop dashboard density. Every primary action should be reachable with the thumb and visually obvious.

Screen padding16–20px mobile
Card radius22–34px

Color behavior

Black is the default. Purple creates atmosphere and special states. Yellow is used sparingly for primary actions, progress, rewards and important feedback.

Background#000 / #050509 / #090912
Primary accent#facc15
Special accent#8b5cf6 / #c084fc

Component language

Components should feel layered, not boxed. Use soft translucent surfaces, blur, large radii, subtle inner highlights and minimal borders.

Interaction rules

The app should feel tactile like a native mobile app. Prefer short spring animations, press compression, soft glow changes and reward feedback over loud animations.

Tap feedbackscale 0.97 → 1.00
Transitions180–280ms
Screen changesfade + slight vertical lift
Rewardssmall glow pulse, not confetti spam

Typography

Use native system fonts. Headlines are bold, tight and premium. Body text stays muted and calm. Avoid overly futuristic fonts because they make it look cheap.

Clan chat pattern

Chat should stay readable and calm. Keep the Deep Space background, but make messages simpler than feature cards. Yellow is only for the user's own messages or important callouts. Purple is for system events, clan milestones and special announcements.

Edge states

The redesign needs rules for boring but important states. These prevent Claude Code from falling back to default browser or SaaS styling when a feature is not represented in the main mockup.

Empty states

Use one small glowing icon/orb, a short headline and one primary action. No huge illustrations.

Loading

Use skeleton cards with soft shimmer or slow opacity pulse. Avoid spinners as the main loading language.

Errors

Use calm dark cards with soft rose accent. Never full red screens. Give one clear recovery action.

Success

Use subtle yellow/purple glow pulse, XP-style feedback and optional haptic-style motion.

Feature mapping rules

For features not shown here, map them by function: feeds become stacked mission cards, settings become quiet grouped lists, chat becomes readable bubbles, ranking becomes compact cards and progress bars, wallet/account areas become premium data cards.
