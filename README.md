# StatR – R Lernpfad

Interaktive Lern-App für das Modul **Computerstatistik** (R). Läuft lokal im Browser, kein Account nötig.

## Start

**Voraussetzung:** Python 3.9 oder neuer installiert.

```bash
git clone https://github.com/ebuart/statr.git
cd statr
python start.py        # Windows
python3 start.py       # macOS / Linux
```

Der Browser öffnet sich automatisch auf `http://localhost:5000`.

## Inhalt

- 15 spielbare Kapitel (R-Grundlagen bis Klassifikation & Clustering)
- 306 Fragen: Multiple Choice, Code-Output, Code-Vervollständigung, Schreib-Aufgaben, Interpretieren, Zuordnung, Wahr/Falsch
- Konzept-Karten vor jeder Übungseinheit
- Fortschritt wird lokal gespeichert (`data/progress.json`)
